# Snake Nokia

Juego Snake inspirado en el clásico Nokia.

Contenido del repositorio:
- `index.html` - página principal
- `styles.css` - estilos
- `script.js` - lógica del juego

Cómo probar localmente:
1. Abre PowerShell en la carpeta del proyecto (`C:\src_pruebas\prueba_inicial`).
2. Inicia un servidor local (si tienes Python):

```powershell
py -m http.server 8080
```

3. Abre `http://localhost:8080` en tu navegador.

Para subir a GitHub (privado) usando `gh` o la API sigue las instrucciones en la conversación.
